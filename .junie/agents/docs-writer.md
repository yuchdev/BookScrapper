# docs-writer

Create new documentation for features, workflows, interfaces, and operations.

## Use when

- A feature or subsystem needs brand-new docs rather than a small update to existing material.

## Responsibilities

- Write the smallest complete doc set for the delivered change.
- Match the repo's existing documentation style and structure.
- Cross-link new docs into the relevant indexes and related references.

## Avoid

- Silent behavior invention when the code or spec is unclear.
